GR!MM INSTALLER

Installs a Felucca firmware package (.fwsc) on your M-VAVE FM-1. Works offline from this one file.

Browser

This browser has no Web MIDI. Open this file in Chrome or Edge.

1 · Package

Drop grimm.fwsc here, or click to choose it

2 · FM-1

Connect the FM-1 with a USB data cable, then press Connect.

3 · Install

Waiting.







Notes


    

  • Close other programs that use the FM-1's MIDI port (DAW, editor tabs, M-UPGRADE).
    • 

  • The FM-1 restarts twice. The screen goes dark for a few seconds; that is normal.
    • 

  • If an install is cut off, replug the USB cable and run it again: the FM-1 stays in update mode until it is finished.
    • 

  • To go back to the official firmware, use the M-VAVE workbench's "return to V15".
    • 

  • If the browser asks for MIDI access with SysEx, allow it. Opened from a file, Chrome asks every time.
    •
